# Ophelia-AI
A SaaS AI Companion Discord Bot.

## Introduction
Ophelia is a personal virtual companion on Discord. Powered by OpenAI’s cutting-edge GPT 4o model; she chats engagingly about anything, supports your mental well-being, and adapts her unique personality to your moods and preferences.




## Features

- Adaptable personality
- Long-term memory
- Pay to play pricing model
- 24/7 uptime




## FAQ

####  How do I use Ophelia?

You can add Ophelia as a bot to your own server or join our official Discord server (https://discord.com/invite/6v56KPZPKD) to try out Ophelia. Use '/register' to automatically link up using your Discord account. Use '/talk' to interact with Ophelia.

#### What are tokens?

Tokens are virtual currency that you can purchase from us. 100 tokens allow you to send approximately 1 message to Ophelia. New users are given 6,000 tokens to use. You can check your token balance at any time using the command '/account' on Discord.
