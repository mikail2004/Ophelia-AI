Frequently Asked Questions

How do I use Ophelia?

keyboard_arrow_down

You can add Ophelia as a bot to your own server or join our official Discord server linked below to try out Ophelia. Use '/register' to automatically link up using your Discord account. Use '/talk' to interact with Ophelia.

What are tokens?

keyboard_arrow_down

Tokens are virtual currency that you can purchase from us. One token is roughly ¾ of a word. Upon registering, you are given 6000 tokens to use. You can check your token balance at any time using the command '/account' on Discord.

How can I make my messages private?

keyboard_arrow_down

You can set your message visibility to 'private' or enable 'DM messaging' for free by using the '/visibility' & '/dms' commands on Discord.
